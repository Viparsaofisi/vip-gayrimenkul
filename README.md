# VIP Gayrimenkul

**Değerli yatırımlar, güçlü yarınlar.**

VIP Gayrimenkul; arsa, arazi, villa ve seçkin gayrimenkul fırsatlarını tanıtmak için geliştirilen modern bir emlak web sitesi projesidir.

## 🌐 Proje Hakkında

Web sitesi, ziyaretçilerin gayrimenkul portföyünü incelemesini, ilanları aramasını ve yatırım bölgeleri hakkında bilgi edinmesini amaçlar.

## ✨ Özellikler

- Siyah ve altın tonlarında premium tasarım
- Gayrimenkul ilanlarını arama ve filtreleme
- Öne çıkan portföy alanı
- Büyükçekmece ve Silivri gibi bölgelere özel tanıtımlar
- Döviz ve değerli madenler için piyasa ekranı
- Gayrimenkul ve yatırım gündemi
- Eyüp Ertal için tanıtım bölümü
- Mobil cihazlarla uyumlu tasarım

## 🛠️ Kullanılan Teknolojiler

- HTML
- CSS
- JavaScript

## 🚧 Proje Durumu

Proje geliştirme aşamasındadır. Örnek ilanlar tasarım amaçlıdır. Canlı piyasa verileri, kalıcı ilan altyapısı ve diğer çevrim içi özellikler sonraki aşamalarda geliştirilecektir.

## 🎯 Hedef

VIP Gayrimenkul markası için ücretsiz barındırma ile başlayıp zamanla gerçek ilanlar, güncel piyasa verileri ve daha gelişmiş özelliklerle büyüyebilen bir web sitesi oluşturmaktır.
